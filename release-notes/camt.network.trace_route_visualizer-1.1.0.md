# Traceroute Route Visualizer 1.1.0

Voer een hostnaam of IP-adres in en start traceroute vanuit CAMT. De optie voor GeoIP toont publieke hops op de wereldkaart via ipapi.co.

Enter a hostname or IP address and run traceroute from CAMT. The GeoIP option maps public hops using ipapi.co.

De verwerking is getest met een gesimuleerd proces. Een live trace vanuit CAMT moet nog worden bevestigd.
