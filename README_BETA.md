# CAMT Professional Edition 1.2.0 Beta 10

This is a beta release of CAMT Professional Edition.

## Purpose of the Beta

Beta 10 is intended to validate the integrated CAMT workflow across network assessment, threat intelligence, evidence correlation, analyst review and professional reporting.

## Important Beta guidance

- Use controlled or authorized environments.
- Save assessments before major workflow changes.
- Treat generated correlations as analyst-supporting evidence, not automatic conclusions.
- Validate important findings against the original technical evidence.
- A missing observation does not prove that a condition is absent.
- CVE applicability requires sufficient product/version evidence.
- Behavioral similarity must not be presented as threat-actor attribution.

## Recommended workflow

1. Build or load network evidence using Network Mapper / NetMap.
2. Perform an Exercise Network Assessment.
3. Review critical assets, choke points, trust boundaries and evidence gaps.
4. Load relevant external CTI when required.
5. Use Behavioral Similarity for actor/M.O. comparison.
6. Use CTI Correlation to compare external intelligence with observed local evidence.
7. Complete analyst review and disposition.
8. Generate the professional report.
